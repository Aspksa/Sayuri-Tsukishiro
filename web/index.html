УСТРОЙСТВА

Мои телефоны

Телефон пока не найден

Подключите Android по USB, включите «Отладку по USB» и подтвердите отпечаток компьютера на телефоне.

USB

Первое подключение

  1. Откройте параметры разработчикаНа Android включите «Отладку по USB».
  2. Подключите кабельРазрешите отладку для этого компьютера на экране телефона.
  3. Нажмите «Обновить»Sayuri увидит авторизованное устройство и разрешит запуск управления.

WI-FI

Беспроводное сопряжение

Android 11+: «Для разработчиков → Беспроводная отладка → Сопряжение устройства с помощью кода».
