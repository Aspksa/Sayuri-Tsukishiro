# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

Проект не привязан к букве диска. Python находится в `.runtime/`, база и пользовательские данные — в `data/`, журналы — в `logs/`.

## Текущие модули

- **Ядро Саюри** — локальный сервер, SQLite, настройки, API и диагностика.
- **Агентное ядро** — контракт будущего ИИ, памяти и инструментов.
- **Диск Sayuri 0.2** — профессиональный локальный файловый менеджер.
- **Веб-интерфейс** — постоянное левое меню, Диск Sayuri и настройки.
- **Инструменты разработки** — версии, тесты и переносимый Windows bootstrap.

## Диск Sayuri 0.2

Рабочий файловый менеджер поддерживает:

- папки и навигацию;
- корзину, восстановление и окончательное удаление;
- избранное и недавние;
- переименование и перемещение;
- массовое выделение и действия;
- поиск, сортировки и фильтры;
- размеры папок;
- подробные свойства;
- SHA-256 и обнаружение дубликатов;
- историю действий;
- загрузку нескольких файлов с процентом передачи;
- сохранение данных локально независимо от буквы носителя.

Следующий слой Диска — версии файлов, паспорт документа, предпросмотр, индексирование, OCR и ИИ-анализ.
