Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

## Sayuri Personal AI

Sayuri теперь присутствует во всём проекте как глобальная AI-помощница.

- клик по плавающему аватару открывает чат;
- правый клик показывает контекстные действия;
- нижний пункт «Личный кабинет Sayuri» открывает её настройки;
- AI-провайдер: Cloud.ru Foundation Models;
- единственная модель: `deepseek-ai/DeepSeek-V4-Flash`;
- API-ключ вводится только локально через Личный кабинет;
- полный ключ не возвращается в web UI и не хранится в GitHub;
- текущий раздел интерфейса передаётся в чат как структурированный контекст.

## Безопасные действия Sayuri

Sayuri может готовить изменяющие действия внутри проекта, но не выполняет их без подтверждения пользователя.

Примеры команд в чате:

- `создай папку Договоры`;
- `добавь этот документ в избранное`;
- `удали этот документ`;
- `перемести этот документ в папку Архив`;
- `запомни как решение проекта: ...`.

Перед изменением появляется карточка с точным действием, уровнем риска и кнопками «Подтвердить» / «Отменить». Повторный confirm не выполняет действие второй раз.

## Память Sayuri

Sayuri имеет локальную долговременную память с двумя строго разделёнными областями:

- личная (`personal`);
- проектная (`project`).

Управление находится в Личном кабинете. Обычные сообщения автоматически не сохраняются. Для быстрого явного сохранения используются фразы «запомни лично: …» и «запомни в проект: …».

## Аватары Sayuri

В Личном кабинете можно назначить отдельные локальные изображения для плавающего аватара, чата, профиля и большого портрета. Поддерживаются PNG/JPEG/WebP; файлы остаются в `data/` и не отправляются в GitHub.

## Evolution Core 0.6

Без новых элементов меню ДНК умеет:
- проводить самопроверку результата;
- блокировать регрессию нового анализа;
- формировать адаптивные ожидания по накопленному корпусу;
- различать candidate/shadow/active правила;
- хранить гипотезы отдельно от фактов;
- выбирать самые полезные факты для будущей проверки;
- объединять одну реальную сущность между разными документами;
- строить план переанализа устаревших ДНК;
- не плодить версии при нескольких одинаковых нажатиях «Переизучить» подряд.

Эволюция основана только на проверяемых данных и обратной связи пользователя.

## Spatial DNA 0.7

Для PDF:
- native text извлекается вместе с геометрией;
- сканированные/малотекстовые страницы направляются в локальный Tesseract OCR;
- факты Evidence Engine могут получить точную страницу и bbox;
- OCR сохраняет confidence;
- spatial snapshot имеет собственный fingerprint и кэш.

Для изображений OCR выполняется локально через Pillow + Tesseract при готовом runtime.

Без vision/semantic AI таблица, подпись и печать называются только кандидатами. Это защищает ДНК от ложной уверенности.
