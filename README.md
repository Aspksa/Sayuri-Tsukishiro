На Windows откройте `Sayuri Tsukishiro.bat`.

- формировать машинную схему документа;
- объединять реальные сущности по устойчивым идентификаторам;

- выявлять временные противоречия;
- узнавать шаблоны и семейства документов;

- объяснять изменения между редакциями;
- калибровать уверенность на подтверждениях пользователя;
- применять коррекцию только после трёх одинаковых исправлений в разных документах;
- вести tamper-evident журнал анализа;

### Evolution Core 0.6

Без новых элементов меню ДНК умеет:
- проводить самопроверку результата;
- блокировать регрессию нового анализа;
- формировать адаптивные ожидания по накопленному корпусу;
- различать candidate/shadow/active правила;
- хранить гипотезы отдельно от фактов;
- выбирать самые полезные факты для будущей проверки;
- объединять одну реальную сущность между разными документами;
- строить план переанализа устаревших ДНК;
- не плодить версии при нескольких одинаковых нажатиях «Переизучить» подряд.

Эволюция основана только на проверяемых данных и обратной связи пользователя.


## Spatial DNA 0.7

ДНК документа умеет работать с пространством страницы без нового пункта меню.

Для PDF:
- native text извлекается вместе с геометрией;
- сканированные/малотекстовые страницы направляются в локальный Tesseract OCR;
- факты Evidence Engine могут получить точную страницу и bbox;
- OCR сохраняет confidence;
- spatial snapshot имеет собственный fingerprint и кэш.

Для изображений:
- OCR выполняется локально через Pillow + Tesseract при готовом runtime.

Без vision/semantic AI таблица, подпись и печать называются только кандидатами. Это защищает ДНК от ложной уверенности.


## Телефон Sayuri

В главном меню есть отдельный модуль **«Телефон Sayuri»**.

Версия 0.1 подключает Android локально через официальный scrcpy/ADB:
- USB;
- Android Wireless Debugging;
- pairing по 6-значному коду;
- запуск управления из интерфейса Sayuri.

На первом этапе экран телефона открывается в локальном окне scrcpy. Проект не открывает общий ADB shell через браузер и не требует облачного аккаунта.


### Телефон Sayuri 0.2

После авторизации Android экран появляется прямо внутри модуля **«Телефон Sayuri»**.

Можно:
- кликать мышью по экрану как пальцем;
- делать свайпы;
- использовать Back / Home / Недавние / Питание;
- переключаться между несколькими авторизованными устройствами;
- при необходимости открыть официальный scrcpy в режиме 60 FPS.

Встроенный режим работает локально через ADB и не предоставляет браузеру произвольный shell.
