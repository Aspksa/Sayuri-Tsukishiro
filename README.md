# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте:

`Sayuri Tsukishiro.bat`

Проект не привязан к букве диска. Локальный Python находится в `.runtime/`, база — в `data/`, журналы — в `logs/`. После успешной проверки Саюри запускает локальный сервер и автоматически открывает браузер.

## Текущие модули

- **Ядро Саюри** — сервер, конфигурация, SQLite и диагностика.
- **Веб-интерфейс** — локальный экран состояния.
- **Инструменты разработки** — версии, тесты и переносимый Windows bootstrap.

Внутренние технические ID модулей не переводятся, чтобы сохранять совместимость кода и истории версий.
