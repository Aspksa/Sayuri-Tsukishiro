# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

Проект не привязан к букве диска. Локальный Python находится в `.runtime/`, база и пользовательские данные — в `data/`, журналы — в `logs/`.

## Текущие модули

- **Ядро Саюри** — сервер, SQLite, системные настройки, API и диагностика.
- **Агентное ядро** — контракт будущего ИИ, памяти и инструментов; модель пока не подключена.
- **Диск Sayuri** — локальное файловое пространство: папки, поиск, загрузка, скачивание, удаление, метаданные и SHA-256.
- **Веб-интерфейс** — постоянное левое меню, главная, Диск Sayuri и настройки.
- **Инструменты разработки** — версии, тесты и переносимый Windows bootstrap.

## Диск Sayuri

В левом меню доступен отдельный раздел **«Диск Sayuri»**. Файлы сохраняются локально внутри проекта и не попадают в Git. Их исходные имена не используются как физические пути хранения.

Первая версия поддерживает:
- папки и навигацию;
- загрузку кнопкой и перетаскиванием;
- поиск в текущей папке;
- скачивание;
- удаление;
- контрольную сумму SHA-256;
- статистику файлов, папок и занятого места.

Следующие этапы: корзина, версии файлов, цифровой паспорт документа, предпросмотр, OCR, индексирование, ИИ-анализ и связи с памятью Саюри.
