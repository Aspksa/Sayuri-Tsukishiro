## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

## Диск Sayuri 0.3

Диск Sayuri — локальный файловый менеджер с центральным просмотром документов и новым слоем **«ДНК»**.

При открытии файла:

**Просмотр → ДНК → Свойства**

ДНК документа локально строит:
- идентичность и SHA-256;
- структуру документа;
- определение типа;
- строки, абзацы, таблицы и заголовки;
- молекулы: даты, суммы, ИНН, VIN, госномера, контакты, номера документов;
- источник каждой молекулы;
- кандидаты сущностей;
- проверки целостности и качества;
- стадии изучения и процент покрытия.

Результат хранится отдельно от оригинала и кэшируется в SQLite.

Интерфейс сделан с минимальным визуальным шумом: наверху только основные показатели, подробности раскрываются по необходимости.

Семантические связи и OCR будут подключены следующим слоем. До подключения реального ИИ-провайдера ДНК не имитирует смысловые выводы.

Пользовательские данные находятся в `data/` и не попадают в Git.
