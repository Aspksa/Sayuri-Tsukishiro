# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

## Диск Sayuri 0.2.2

Диск Sayuri — локальный файловый менеджер проекта.

Текущий интерфейс:
- широкий, но ограниченный комфортной шириной рабочий холст;
- верхние разделы «Все файлы», «Избранное», «Недавние», «Корзина»;
- режимы «Плитки» и «Список»;
- крупные карточки папок с количеством файлов и размером;
- длинные названия до трёх строк;
- крупная кликабельная строка пути;
- drag-and-drop файлов и папок;
- массовый drag-and-drop выделения;
- перенос на папку или прямо в корзину;
- автооткрытие папки при удержании;
- уведомление с «Отменить» после переноса;
- центральный просмотр и свойства;
- локальный просмотр PDF, изображений, аудио, видео, текстовых и современных Office/ODF-файлов.

Пользовательские данные находятся в `data/` и не попадают в Git.
