# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

## Диск Sayuri

Текущая версия модуля: **0.2.1**.

Диск Sayuri поддерживает папки, корзину, восстановление, избранное, недавние, массовые операции, сортировки, фильтры, полный размер папок, SHA-256, обнаружение дубликатов и загрузку с процентом передачи.

Файл открывается в **центральном окне**. Там есть вкладки **«Просмотр»** и **«Свойства»**. В свойствах можно переименовать объект, добавить его в избранное, переместить, скачать или отправить в корзину.

Поддержан локальный просмотр:
- PDF;
- изображений;
- аудио и видео;
- текстовых форматов;
- DOCX;
- XLSX;
- PPTX;
- ODT/ODS/ODP.

Контекстное меню доступно по **правой кнопке мыши** и через кнопку `•••`.

Пользовательские данные находятся в `data/` и не попадают в Git.
