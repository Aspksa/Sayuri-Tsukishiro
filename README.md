# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — новый проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Версия исходников: [VERSION](VERSION). Версии модулей находятся в их папках; правило любого изменения — [VERSIONING.md](VERSIONING.md). Номер исходников не означает опубликованный GitHub Release.

## С чего начать новому чату или разработчику

1. Прочитать [AGENTS.md](AGENTS.md) — порядок работы.
2. Прочитать [PROJECT_STATE.md](PROJECT_STATE.md) — точка остановки и подтверждённый результат.
3. Прочитать [DECISIONS.md](DECISIONS.md) — что уже решено и что остаётся предложением.
4. Найти текущую задачу в [TASKS.md](TASKS.md); для кода открыть [DEVELOPMENT.md](DEVELOPMENT.md).
5. Прочитать [VERSIONING.md](VERSIONING.md): любое изменение повышает проект и затронутые модули.
6. Проверить актуальную ветку, последние коммиты и [CHANGELOG.md](CHANGELOG.md), затем сверить записи с файлами.

Текущий статус приложения хранится в `PROJECT_STATE.md`. Подтверждённые команды установки и запуска — в `DEVELOPMENT.md`; если они ещё не появились, не придумывать их.

## Сообщение для следующего чата

> Работаем над https://github.com/Aspksa/Sayuri-Tsukishiro. Прочитай AGENTS.md, PROJECT_STATE.md и DECISIONS.md в актуальной ветке main, затем текущую задачу в TASKS.md. Проверь HEAD, последние коммиты и нужные файлы; команды и структуру смотри в DEVELOPMENT.md. Кратко сообщи, что подтверждено, где остановились и какой шаг выполняешь по моей задаче. Не повторяй уже решённые вопросы и не переноси решения других проектов автоматически. Продолжай в рамках моей текущей задачи. При любом изменении повышай версию проекта и затронутых модулей по VERSIONING.md. После изменений обнови контрольную точку, статус задачи и журнал; подтвердить публикацию нужно по фактической ветке. Если доступа к GitHub нет, скажи об этом и попроси нужные файлы или архив.
