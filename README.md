# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

## Диск Sayuri 0.5

Внешне интерфейс не усложнился:

**Просмотр → ДНК → Свойства**

Но внутренний движок ДНК теперь дополнительно умеет:

- строить spatial-ready доказательства;
- формировать машинную схему документа;
- объединять реальные сущности по устойчивым идентификаторам;
- извлекать обязательства и сроки;
- разрешать ссылки на другие документы;
- выявлять временные противоречия;
- узнавать шаблоны и семейства документов;
- находить аномалии относительно накопленного корпуса;
- объяснять изменения между редакциями;
- калибровать уверенность на подтверждениях пользователя;
- применять коррекцию только после трёх одинаковых исправлений в разных документах;
- вести tamper-evident журнал анализа;
- защищать будущий ИИ от prompt injection внутри файлов;
- классифицировать чувствительные данные;
- собирать минимальный безопасный AI-context;
- поддерживать строгий путь `fact → confirmed → knowledge`;
- строить общую ДНК пакета документов в папке.

Оригинальные файлы не изменяются и не отправляются наружу.

OCR и реальный семантический ИИ остаются следующими слоями.
