# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

Проект не привязан к букве диска. Локальный Python находится в `.runtime/`, база — в `data/`, журналы — в `logs/`.

## Текущие модули

- **Ядро Саюри** — сервер, SQLite, системные настройки, API и диагностика.
- **Агентное ядро** — контракт будущего AI/Memory/Tool исполнения; модель пока не подключена.
- **Веб-интерфейс** — постоянное левое меню, главная и раздел «Настройки».
- **Инструменты разработки** — версии, тесты и переносимый Windows bootstrap.

## CORE-002

В интерфейсе слева доступны «Главная» и «Настройки». В «Настройках» находятся конфигурация системы, состояние ядра/БД/сервера, события и фактическая архитектура модулей.

Настройки сохраняются в SQLite и проверяются сервером. API CORE-002: `/api/system`, `/api/settings`, `/api/events`.
