# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Текущая версия: [VERSION](VERSION).

## Быстрый запуск

На Windows откройте `Sayuri Tsukishiro.bat`.

## Диск Sayuri 0.4

Внешне открытие файла остаётся простым:

**Просмотр → ДНК → Свойства**

Новые возможности добавлены внутрь ДНК, без новых визуальных панелей.

ДНК 0.4 умеет локально:

- нормализовать факты в машинный формат;
- хранить стабильные ID и доказательства каждого факта;
- разделять уверенность извлечения, нормализации и источника;
- проверять обязательные поля разных типов документов;
- разбирать реквизиты, транспорт, суммы, количество, время и действия;
- проверять арифметику таблиц;
- выявлять внутренние и междокументные расхождения;
- строить semantic fingerprint;
- находить точные и почти-дубли;
- канонизировать сущности;
- готовить доказуемый graph-ready слой;
- применять quality gate перед будущей памятью;
- хранить версии ДНК и изменения между анализами;
- переиспользовать контентный анализ при изменении только имени/пути;
- хранить обратную связь и исправления фактов.

ДНК не отправляет документы наружу и не изменяет оригинал.

OCR и настоящий семантический ИИ пока не подключены, поэтому сложные причинные связи и непроверенные выводы не имитируются.

Пользовательские данные находятся в `data/` и не попадают в Git.
