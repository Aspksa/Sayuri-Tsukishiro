# Sayuri-Tsukishiro

**Саюри Цукисиро / Sayuri Tsukishiro** — новый проект личной AI-помощницы.

Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro  
Основная ветка: `main`  
Предложенная первая версия: `v0.1.0 «Пробуждение»` — ещё не выпущена.

## С чего начать новому чату или разработчику

1. Прочитать [AGENTS.md](AGENTS.md) — правила работы и передачи контекста.
2. Прочитать [PROJECT_STATE.md](PROJECT_STATE.md) — что сделано, где остановились, что делать дальше.
3. Посмотреть [CHANGELOG.md](CHANGELOG.md) и последние коммиты.
4. Сверить записи с актуальными файлами выбранной ветки.

**Сейчас:** подготовлены документы для передачи работы между чатами. Код приложения, зависимости и команды запуска пока отсутствуют. Актуальная точка остановки хранится в `PROJECT_STATE.md`.

## Сообщение для следующего чата

> Работаем над https://github.com/Aspksa/Sayuri-Tsukishiro. Прочитай AGENTS.md, PROJECT_STATE.md и CHANGELOG.md в актуальной ветке main, затем проверь последние коммиты и файлы. Кратко сообщи, что сделано, где остановились и какой следующий шаг. Продолжай в рамках моей текущей задачи; после изменений обнови PROJECT_STATE.md и CHANGELOG.md. Если доступа к GitHub нет, скажи об этом и попроси эти файлы.

Доступ к GitHub и чтение этих документов нужны каждому новому чату отдельно. Документы передают состояние работы; они не подключают чат к репозиторию автоматически.
