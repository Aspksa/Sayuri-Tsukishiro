## Проблемы и ограничения

- По выполненным проверкам известных ошибок инструмента нет.
- `bump` и `check` требуют Git-копию. В ZIP без Git доступны текстовые VERSION и команда `show`.
- У инструментов нет фонового наблюдателя: номер повышает команда или разработчик перед коммитом. CI обнаруживает пропуск.
- Прикладной стек ещё не выбран; помощница не запускается как приложение на этом этапе.
- При расхождении документации и более свежего кода сначала проверь историю и текущие файлы.
