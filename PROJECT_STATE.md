## Memory Intelligence 2.0

Новый модуль: `agent/memory_intelligence.py`.

Цепочка:

```text
сообщение пользователя
→ Memory Guardian
→ классификация потенциально важного
→ проверка области personal/project
→ поиск дубля
→ проверка возможного противоречия
→ кандидат памяти
→ подтверждение/отклонение пользователя
→ долговременная память
→ релевантный контекст для DeepSeek-V4-Flash
```

Обычная переписка целиком в долговременную память не копируется.

## Что Sayuri теперь замечает сама

Локальный детерминированный анализатор распознаёт, в частности:

- личные предпочтения: «я предпочитаю…», «мне нравится…», «я не хочу…»;
- проектные решения: «решили…», «фиксируем…», «будем использовать…», «используем только…»;
- правила проекта;
- потенциальные проектные задачи;
- отдельные технические факты проекта.

Каждый кандидат получает:

- область `personal` или `project`;
- тип `fact/preference/decision/task/note`;
- confidence;
- importance;
- причину выделения;
- источник;
- контекст текущего экрана;
- ссылку на открытый документ, если он был;
- отношение `new/duplicate/conflict`;
- статус проверки.

## Защита памяти

Memory Guardian не доверяет содержимому сообщения как инструкции для системы.

По умолчанию:

- генерация кандидатов — включена;
- поиск возможных противоречий — включён;
- привязка интерфейсного контекста — включена;
- автоматическое сохранение новых кандидатов — выключено.

Автосохранение можно включить в Личном кабинете. Даже тогда оно разрешено только для высокоуверенных проектных фактов и только выше порога 96–100%. Решения и личные предпочтения автоматически не сохраняются.

## Дубли и противоречия

Точный или почти идентичный кандидат маркируется как `duplicate` и не создаёт вторую запись памяти.

Если новый кандидат достаточно похож на существующую запись, но имеет противоположную полярность, он маркируется `conflict` и требует решения пользователя.

При подтверждении конфликта новая память получает ссылку `supersedes_id` на связанную предыдущую запись. Старое воспоминание не удаляется автоматически.

## Provenance

Записи памяти теперь поддерживают:

- `source_context`;
- `confidence`;
- `supersedes_id`.

Это позволяет видеть, откуда появилась память и с каким контекстом она была связана.

## Личный кабинет

В разделе памяти добавлено:

- счётчик «На проверку»;
- Memory Intelligence 2.0;
- очередь кандидатов;
- «Сохранить» / «Не запоминать»;
- отдельное отображение возможных конфликтов;
- confidence кандидата;
- причина выделения;
- источник/имя открытого документа;
- настройки автоматизации;
- порог автосохранения.

В чате после ответа Sayuri показывает уведомление, если она заметила новый кандидат памяти, и предлагает открыть память для проверки.
