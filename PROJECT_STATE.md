## Диск Sayuri 0.2

Реализован профессиональный файловый слой:

- «Мой диск», «Избранное», «Недавние», «Корзина».
- Мягкое удаление и восстановление файлов и целых деревьев папок.
- Окончательное удаление из корзины.
- Переименование файлов и папок.
- Перемещение одиночных и нескольких объектов.
- Защита от перемещения папки в собственнее дочернее дерево.
- Массовое выделение и массовые действия.
- Избранное.
- Сортировка по имени, дате, размеру и типу.
- Фильтры по папкам, документам, PDF, таблицам, презентациям, изображениям, видео, аудио и архивам.
- Рекурсивный размер папок.
- Панель свойств объекта.
- Путь, даты, MIME-тип, SHA-256 и число совпадений файла.
- История действий Диска.
- Обнаружение дубликатов по SHA-256 при загрузке.
- Очередь загрузок и реальный процент передачи через XMLHttpRequest upload progress.
- Конфликты имён проверяются без опасной жёсткой миграции старой базы.
- Существующая схема Диска 1 автоматически мигрирует в схему 2 без удаления файлов.

## Хранение

- Бинарные объекты: `data/disk/objects/`.
- Временные загрузки: `data/disk/temp/`.
- Метаданные: SQLite `data/sayuri.db`.
- Схема Диска: 2.
- Максимальный размер одного файла: 1 ГБ.
- Файлы хранятся под UUID; пользовательское имя не используется как физический путь.

## API 0.2

- `GET /api/disk` — список, поиск, область, сортировка и фильтр.
- `GET /api/disk/actions` — история действий.
- `GET /api/disk/folders-tree` — дерево назначения для перемещения.
- `GET /api/disk/items/{kind}/{id}` — свойства.
- `POST /api/disk/folders` — создать папку.
- `POST /api/disk/upload` — загрузить файл.
- `POST /api/disk/rename` — переименовать.
- `POST /api/disk/move` — переместить.
- `POST /api/disk/favorite` — изменить избранное.
- `POST /api/disk/trash` — в корзину.
- `POST /api/disk/restore` — восстановить.
- `POST /api/disk/delete-permanent` — удалить навсегда.
- `GET /api/disk/files/{id}/download` — скачать.

## Макет интерфейса

Рабочий макет встроен непосредственно в сайт: отдельная внутренняя навигация Диска, панель статистики, таблица, массовая панель, сортировки/фильтры, очередь загрузки, свойства справа, окно перемещения и история операций.
