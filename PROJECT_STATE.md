## Долговременная память Sayuri

Новый локальный контур: `agent/memory.py`.

Память хранится в отдельной локальной SQLite-базе:

`data/sayuri-memory.db`

Каталог `data/` исключён из Git.

### Области памяти

- `personal` — личная память;
- `project` — проектная память.

Области не объединяются в одну запись. При передаче памяти в AI они сохраняются отдельными массивами с явной меткой области.

### Типы записей

- `fact`;
- `preference`;
- `decision`;
- `task`;
- `note`.

Каждая запись также имеет важность 1–5, источник, даты создания/изменения и счётчик использования.

### Поведение

- одинаковые записи в одной области и одном типе не дублируются;
- поиск для чата выбирает только лексически релевантные записи;
- обычная переписка автоматически в долговременную память не сохраняется;
- явные команды сохраняются детерминированно:
  - `запомни лично: ...`;
  - `запомни в проект: ...`;
- если Cloud.ru ещё не настроен, явная команда памяти всё равно сохраняется локально и получает локальное подтверждение;
- при обычном AI-запросе релевантная память передаётся DeepSeek-V4-Flash как справочные данные, а не как инструкции.

## Студия аватаров Sayuri

Новый локальный контур: `agent/avatar.py`.

Пользователь может хранить разные изображения для разных мест интерфейса.

Слоты:

- `orb` — плавающий аватар, рекомендуется 192×192;
- `chat` — чат, рекомендуется 256×256;
- `profile` — компактный профиль, рекомендуется 512×512;
- `hero` — большой портрет, рекомендуется 1024×1024.

Поддерживаются PNG, JPEG и WebP до 8 МБ.

Загруженные варианты сохраняются в:

`data/sayuri-avatars/`

Оригинальный встроенный образ остаётся fallback для каждого незаполненного слота.

API:

- `GET /api/sayuri/avatars`;
- `GET /api/sayuri/avatar/{slot}`;
- `POST /api/sayuri/avatar/upload?slot=...`;
- `DELETE /api/sayuri/avatar/{slot}`.

### Защита

- пользовательские изображения не записываются в GitHub;
- имя хранимого файла формируется по SHA-256, а не из пользовательского пути;
- разрешены только PNG/JPEG/WebP;
- проверяется MIME/магическая сигнатура;
- максимум 8 МБ;
- для определяемых форматов проверяются размеры 32×32…8192×8192.
