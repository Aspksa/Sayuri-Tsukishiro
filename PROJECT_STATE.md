## Диск Sayuri 0.2.1

- Удалён нижний пользовательский блок «История действий».
- Зона «Перетащите файлы сюда» перенесена выше карточек «Файлы / Папки / Занято / Избранное / Корзина».
- Добавлено контекстное меню по правой кнопке мыши.
- Меню `•••` использует тот же набор действий, что и правый клик.
- Длинные имена файлов и папок переносятся на несколько строк и доступны целиком.
- Щелчок по файлу открывает крупное центральное окно просмотра.
- Свойства перенесены из правой выезжающей панели в центральное окно.
- В свойствах можно переименовать объект и изменить статус «Избранное».
- Добавлена улучшенная иерархия папок в левой панели Диска.
- PDF, изображения, видео и аудио открываются встроенно.
- TXT/MD/JSON/XML/CSV/LOG/INI/CFG/YAML открываются как текст.
- DOCX и PPTX открываются через локальное извлечение текста.
- XLSX открывается как таблица (до 200 отображаемых строк и 50 значений в строке).
- ODT/ODS/ODP открываются через локальное извлечение текста.
- Для неподдерживаемых форматов сохраняются скачивание и открытие внешним приложением.
- Предпросмотр не изменяет оригинал файла.

## Безопасность и совместимость

- Схема Диска остаётся 2: обновление не требует новой миграции пользовательских данных.
- Файлы остаются в `data/disk/objects/` под UUID.
- Просмотр Office Open XML выполняется локально стандартной библиотекой Python без отправки документов наружу.
- Сервер остаётся только на `127.0.0.1`.
