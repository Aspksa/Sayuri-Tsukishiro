## Sayuri Personal AI 0.1

В проект внедрён первый рабочий AI-контур Sayuri.

### Глобальное присутствие

Sayuri присутствует поверх всех разделов интерфейса как плавающий аватар.

- обычный клик по Sayuri открывает отдельное плавающее окно чата;
- правый клик открывает контекстное меню быстрых действий;
- аватар можно перетаскивать;
- положение сохраняется локально в браузере;
- текущий раздел и выбранный документ входят в интерфейсный контекст чата;
- содержимое документов автоматически во внешний AI не отправляется.

### Личный кабинет Sayuri

В нижней части левого меню находится отдельный пункт «Личный кабинет Sayuri».

В кабинете доступны:

- профиль Sayuri;
- состояние AI;
- фиксированный провайдер Cloud.ru;
- фиксированная модель `deepseek-ai/DeepSeek-V4-Flash`;
- ввод API-ключа;
- проверка подключения;
- удаление локального ключа;
- управление видимостью Sayuri;
- сохранение положения;
- локальная история чата;
- сводка текущего интерфейсного контекста.

### Cloud.ru

Единственный AI-провайдер на этом этапе — Cloud.ru Foundation Models.

- Base URL: `https://foundation-models.api.cloud.ru/v1`.
- Model ID: `deepseek-ai/DeepSeek-V4-Flash`.
- Выбор другой модели в UI отсутствует намеренно.
- API использует OpenAI-compatible методы `GET /v1/models` и `POST /v1/chat/completions`.
- В браузер полный API-ключ после сохранения не возвращается.

### Защита API-ключа

Ключ не хранится в GitHub и не записывается в `MODULES.json`, документацию или обычные системные настройки.

При вводе через Личный кабинет он сохраняется в локальном `data/sayuri-cloudru.secret`:

- Windows: шифрование DPAPI профиля текущего пользователя;
- другие ОС: локальный файл с правами `0600` для разработки/CI;
- переменная окружения `SAYURI_CLOUDRU_API_KEY` имеет приоритет над файлом;
- публичный API возвращает только маску ключа.

Каталог `data/` уже исключён из Git.

## API Sayuri

- `GET /api/sayuri/profile`
- `POST /api/sayuri/provider`
- `POST /api/sayuri/provider/test`
- `POST /api/sayuri/chat`

Чат передаёт модели нормализованную историю последних сообщений и безопасный интерфейсный контекст. Инструменты изменения проекта и долговременная память пока не включены.

## Активная архитектура

1. `app/` — локальное ядро, SQLite, HTTP API, настройки и интеграция Agent Core.
2. `agent/` — контракт и реальный runtime Sayuri/Cloud.ru.
3. `disk/` — Диск, ДНК 0.7, Evidence Engine, Evolution Core, Spatial Intelligence и OCR.
4. `web/` — глобальная Sayuri, чат, Личный кабинет, Диск и системный UI.
5. `scripts/` — переносимый Windows bootstrap и проверки.

## Ограничения текущего этапа

- долговременная личная память Sayuri ещё не подключена к чату;
- tools/actions Agent Core ещё не разрешены;
- документ автоматически не отправляется в Cloud.ru;
- ответы сейчас не stream-ятся по токенам;
- история чата хранится локально в браузере, если пользователь не отключил это.
