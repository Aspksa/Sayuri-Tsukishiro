- браузер открыт автоматически;
- `/`, `/styles.css`, `/app.js`, `/api/health`, `/api/events` отвечали успешно.

В логе обнаружены два дефекта 0.1.2: `ConnectionAbortedError [WinError 10053]` при раннем закрытии health-check и лишняя ошибка для `/favicon.ico`.

## Исправлено в 0.1.3

- health-check полностью дочитывает тело ответа перед закрытием соединения;
- `BrokenPipeError`, `ConnectionResetError`, `ConnectionAbortedError` считаются отключением клиента, а не `SAYURI-CORE-500`;
- сервер не пытается отправлять повторный 500-ответ в уже закрытый сокет;
- `/favicon.ico` больше не создаёт ошибку; добавлен `web/favicon.svg`;
- видимые названия модулей: «Ядро Саюри», «Веб-интерфейс», «Инструменты разработки»;
- события сокращены: «Запуск: Ядро готово», «Сайт: Сервер готов», «Остановка: Ядро остановлено»;
- старые `core.start/web.ready/core.stop` автоматически переводятся в существующей SQLite;
- интерфейс, preflight, launcher и диагностические сообщения переведены на русский;
- внутренние ID модулей сохранены на английском для совместимости версионирования.

- AI-провайдер, чат, память знаний и инструменты агента ещё не реализованы.

- Первый запуск на новом носителе требует интернет только для получения локального Python runtime, если `.runtime/python` ещё отсутствует.
