## Реализовано

- Постоянное левое меню: «Главная» и «Настройки».
- В «Настройки» перенесены конфигурация, состояние, события и архитектура.
- SQLite schema 2 с таблицей `system_settings`.
- Типизированные настройки: автозапуск браузера, интервал обновления, лимит событий, HTTP-журнал.
- API: `GET /api/system`, `GET /api/settings`, `POST /api/settings`, `GET /api/events`.
- Новый модуль `agent/` — «Агентное ядро».
- Agent Core имеет контракт запроса/результата, но AI-провайдер, память и инструменты пока отключены.
- Архитектура интерфейса строится из фактического `MODULES.json`.

## База данных

Существующая SQLite обновляется до schema 2 без удаления событий и ошибок. Новые значения настроек создаются только при отсутствии и не затирают выбор пользователя.

## Проверки

После публикации CI должен выполнить тесты версий, ядра, БД, настроек, API, Agent Core, веб-контракта, preflight и Windows launcher check.
