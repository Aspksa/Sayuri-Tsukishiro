# Текущее состояние Sayuri-Tsukishiro

- Дата: 2026-10-05.
- Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro

- Базовая ревизия DISK-001: `cacf81a3fb8dceb4194137e4ac3fbd5865aaf468`.
- Задача: DISK-001 — первый рабочий модуль «Диск Sayuri».
- Версия исправления CI: проект `0.1.7`; Ядро Саюри `0.1.4`; Веб-интерфейс `0.1.3`; Диск Sayuri `0.1.0`.

## Реализовано

- В левом меню добавлен отдельный пункт **«Диск Sayuri»**.
- Модуль `sayuri-disk` имеет собственную версию `0.1.0`.
- Файлы хранятся в `data/disk/objects/` под UUID.
- Метаданные находятся в SQLite; для файла сохраняются имя, MIME-тип, размер, SHA-256, папка и дата.
- Папки, хлебные крошки, поиск в текущей папке.
- Загрузка кнопкой и перетаскиванием.
- Потоковая запись по 1 МБ без загрузки всего файла в память.
- Лимит одного файла: 1 ГБ.
- Скачивание с SHA-256, удаление файлов и только пустых папок.
- Проверка имён от обхода путей и управляющих символов.
- События Диска записываются в системный журнал.

## API Диска Sayuri

- `GET /api/disk`
- `POST /api/disk/folders`
- `POST /api/disk/upload`
- `GET /api/disk/files/{id}/download`
- `DELETE /api/disk/files/{id}`
- `DELETE /api/disk/folders/{id}`
