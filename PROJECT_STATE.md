# Текущее состояние Sayuri-Tsukishiro

## Контрольная точка

- Дата: 2026-10-05.
- Репозиторий: https://github.com/Aspksa/Sayuri-Tsukishiro
- Ветка: `main`.
- Базовая ревизия: `22d1111826145d08f46ef74422fe806510f18896`.
- Задача: DISK-002.2 — широкий интерфейс и настоящее перемещение мышью.
- Версия результата: проект `0.1.10`; Ядро Саюри `0.1.7`; Диск Sayuri `0.2.2`; Веб-интерфейс `0.2.2`.

## Что изменено

- Убран второй внутренний сайдбар Диска.
- «Все файлы / Избранное / Недавние / Корзина» перенесены в компактную верхнюю панель.
- Рабочая область Диска расширена до комфортного максимума 1380 px, но не растягивается бесконтрольно на весь монитор.
- Добавлены режимы «Плитки» и «Список» с сохранением выбора в браузере.
- Папки в плитках крупнее; имя отображается до трёх строк.
- В карточке папки показывается рекурсивная сводка: количество файлов и общий размер.
- Строка пути увеличена и каждый уровень кликабельный.
- Реализован настоящий drag-and-drop файлов и папок.
- Выделенная группа переносится одним drag-and-drop.
- Папка подсвечивается при наведении.
- После удержания над папкой около 900 мс она автоматически открывается.
- Файлы и папки можно перетащить прямо на кнопку «Корзина».
- После перемещения или отправки в корзину появляется уведомление с кнопкой «Отменить».
- Сервер возвращает исходные папки каждого перемещённого объекта и поддерживает атомарную отмену через `/api/disk/undo-move`.
- Окно «Переместить» расширено примерно до 720 px и разделено на список папок и карточку выбранного назначения.

## Проверки

CI должен проверить:
- перемещение и отмену на уровне сервиса;
- API `/api/disk/move` и `/api/disk/undo-move`;
- рекурсивные размеры и количество файлов;
- отсутствие второго сайдбара;
- наличие режимов «Плитки / Список»;
- drag-and-drop и корзину;
- preflight, version check и Windows launcher.
