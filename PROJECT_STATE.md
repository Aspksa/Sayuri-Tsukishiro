## Исправление DNA Upload 0.1

Проверка показала две пользовательские проблемы.

Первая: обычная загрузка файла через «Диск Sayuri» только сохраняла оригинал. ДНК не запускалась после успешной загрузки и начинала строиться только при последующем открытии вкладки «ДНК».

Вторая: если построение ДНК завершалось ошибкой, сообщение уходило в общий блок Диска за модальным окном документа. В самой вкладке оставалось состояние «Изучение документа…», что выглядело как зависание.

## Новое поведение

Для поддерживаемых документов и изображений:

```text
загрузка файла
→ оригинал безопасно сохранён
→ файл сразу появляется в Диске
→ автоматический POST /dna/analyze
→ статус ДНК показывается прямо в очереди загрузки
→ готовая ДНК кэшируется
```

Автоматическая ДНК включена для PDF, текстовых форматов, DOCX/PPTX/XLSX, ODF и основных изображений.

Загрузка оригинала и анализ разделены. Ошибка ДНК не удаляет уже загруженный файл и не останавливает загрузку остальных файлов.

## Состояния в очереди загрузки

Теперь видны отдельные состояния:

- «Файл загружен · ожидает ДНК»;
- «Строю ДНК…»;
- «Готово · ДНК N%»;
- «Файл загружен · ошибка ДНК: …».

После пачки файлов показываются отдельные счётчики успешных загрузок и успешных ДНК.

## Ошибки внутри вкладки ДНК

В самой вкладке добавлен `#dna-load-state`.

Он показывает:

- активный анализ;
- пояснение, что OCR сканированного PDF может занять время;
- готовность и процент покрытия;
- точную ошибку анализа;
- кнопку «Повторить анализ».

При ошибке интерфейс больше не остаётся в ложном бесконечном состоянии «Изучение документа…».

## Spatial/OCR diagnostics

Исправлена ошибка диагностики: `spatial_status()` проверял несуществующий флаг `pymupdf_available`.

Канонический Spatial Engine использует PDFium и возвращает `pdfium_available`, поэтому именно этот флаг теперь определяет состояние готовности PDF spatial extraction.

Добавлены/усилены проверки:

- Web contract требует автоматический запуск ДНК после upload;
- Web contract требует видимую ошибку и retry внутри вкладки ДНК;
- Spatial DNA test проверяет корректный PDFium readiness flag;
- существующие Disk API tests продолжают проверять upload → DNA → reanalyze;
- JavaScript syntax, preflight и Windows launcher остаются обязательными.

Перед публикацией в `main` итог собирается одним атомарным коммитом от `0.1.39` и проходит полный workflow Versions.
