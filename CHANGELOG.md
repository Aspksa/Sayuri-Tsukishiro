# Журнал изменений

## Невыпущенные изменения

### 0.1.4 — 2026-10-05 — Совместимость Windows launcher

- Исправлена проблема кодировки, из-за которой CMD видел части русских строк как команды, а Windows PowerShell 5.1 выдавал ParserError.
- BAT сделан ASCII-safe.
- PowerShell bootstrap сохранён как UTF-8 с BOM и явно настраивает UTF-8 консольный ввод/вывод.
- Добавлены тесты BOM/ASCII.
- GitHub Actions теперь включает отдельную проверку launcher на `windows-latest` через Windows PowerShell.
- Версия `dev-tools` повышена до `0.1.3`.

### 0.1.3 — 2026-10-05 — Чистый Windows-запуск и русский интерфейс

- Исправлена обработка `ConnectionAbortedError [WinError 10053]`.
- Health-check дочитывает ответ.
- Добавлен favicon.
- Видимые названия модулей, события, интерфейс и основные сообщения переведены на русский.
- Версии: ядро `0.1.1`, веб `0.1.1`, инструменты `0.1.2`.

### 0.1.2 — 2026-10-05 — Первое рабочее ядро

- Добавлены ядро, SQLite, веб-интерфейс и переносимый Windows launcher.
- Настроены тесты и GitHub Actions.

### 0.1.1 — 2026-10-05 — Версии проекта и модулей

- Введены VERSION, MODULES.json, модульные версии и автоматическая проверка.
