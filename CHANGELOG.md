# Журнал изменений

Здесь фиксируются значимые изменения проекта. Точные коммиты и авторы доступны в истории Git.

## Невыпущенные изменения

### 0.1.1 — 2026-10-05 — Версии проекта и модулей

- Зафиксирована первая версия исходников в VERSION: 0.1.1; раньше 0.1.0 было только предложением.
- Добавлен служебный модуль dev-tools 0.1.0 с собственным scripts/VERSION.
- Добавлены MODULES.json и правило: любое изменение повышает проект, изменение модуля повышает также его номер.
- Реализованы просмотр, повышение PATCH и проверка версий; повторное повышение относительно одного основания не дублируется.
- Добавлены 13 интеграционных тестов и workflow проверки каждого коммита проверяемого диапазона.
- Обновлены инструкции, решения, задачи и состояние проекта. Приложение и GitHub Release не создавались.

### 2026-10-05 — Уточнение правил продолжения работы

- Расширен AGENTS.md: приоритет источников, точные контрольные точки, восстановление после прерывания, проверка публикации и работа с неудачными попытками.
- Добавлен DECISIONS.md: решения, источники и открытые вопросы без автоматического переноса других проектов.
- Добавлен TASKS.md: статусы, зависимости и критерии готовности; разработка приложения отмечена как предложенный следующий этап.
- Добавлен DEVELOPMENT.md: карта файлов и справочник будущих подтверждённых команд.
- Обновлены PROJECT_STATE.md и README.md; разделены текущий статус, устойчивые решения и история.
- Изменения ограничены документацией; приложение и релиз не создавались.

### 2026-10-05 — Передача работы между чатами

- Добавлен AGENTS.md: порядок чтения проекта и правила обновления состояния.
- Добавлен PROJECT_STATE.md: выполненные действия, точка остановки, проверки и следующий шаг.
- Расширен README.md: навигация по документации и готовое сообщение для нового чата.
