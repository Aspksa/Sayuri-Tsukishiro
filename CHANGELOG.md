# Журнал изменений

## Невыпущенные изменения

### 0.1.3 — 2026-10-05 — Чистый Windows-запуск и русский интерфейс

- Исправлена обработка `ConnectionAbortedError [WinError 10053]`: отключение HTTP-клиента больше не считается `SAYURI-CORE-500`.
- Health-check теперь дочитывает тело ответа перед закрытием соединения.
- Добавлен favicon и безопасная обработка `/favicon.ico`.
- Все видимые названия модулей переведены: «Ядро Саюри», «Веб-интерфейс», «Инструменты разработки».
- Системные события сокращены и переведены на русский; старые записи автоматически мигрируют.
- Русифицированы веб-интерфейс, launcher, preflight и основные сообщения ядра.
- Добавлены тесты отключения клиента, favicon и перевода старых событий.
- Версии: `sayuri-core 0.1.1`, `web-ui 0.1.1`, `dev-tools 0.1.2`.

### 0.1.2 — 2026-10-05 — Первое рабочее ядро

- Добавлены модули `sayuri-core 0.1.0` и `web-ui 0.1.0`; `dev-tools` повышен до `0.1.1`.
- Реализованы SQLite schema 1, журнал событий/ошибок, health/events API и локальный HTTP-сервер.
- Добавлен адаптивный веб-экран состояния системы.
- Добавлен переносимый `Sayuri Tsukishiro.bat` и PowerShell bootstrap с Python 3.14.8, SHA256 verification и автоматическим открытием браузера.
- Добавлены app/launcher tests, preflight и их запуск в GitHub Actions.
- Добавлен `ERRORS.md` и runtime-логи; `.runtime/`, `data/`, `logs/` исключены из Git.

### 0.1.1 — 2026-10-05 — Версии проекта и модулей

- Зафиксирована первая версия исходников в VERSION.
- Добавлен служебный модуль dev-tools.
- Реализованы просмотр, повышение PATCH и проверка версий.
- Добавлены интеграционные тесты и GitHub workflow.
