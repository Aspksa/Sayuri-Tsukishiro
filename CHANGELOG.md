# Журнал изменений

## Невыпущенные изменения

### 0.1.7 — 2026-10-05 — Исправление проверки HTTP-контракта

- Исправлена тестовая заглушка `_headers` после добавления дополнительных заголовков скачивания.
- Производственный код «Диск Sayuri» не изменён.
- Ядро Саюри повышено до `0.1.4` по правилу версионирования проекта.

### 0.1.6 — 2026-10-05 — Диск Sayuri

- В левое меню добавлен отдельный модуль **«Диск Sayuri»**.
- Создан модуль `sayuri-disk 0.1.0`.
- Добавлены папки, поиск, загрузка файлов, drag-and-drop, скачивание и удаление.
- Файлы сохраняются под UUID в `data/disk/objects`; реальные имена остаются только в метаданных.
- Для каждого файла сохраняются SHA-256, размер, MIME-тип, папка и дата.
- Загрузка выполняется потоково и ограничена 1 ГБ на один файл.
- Добавлена защита имён от обхода путей и управляющих символов.
- Добавлены статистика Диска и его состояние в системный API.
- Добавлены тесты сервиса, HTTP API и веб-контракта.
- CI подтвердил новые тесты Диска; отдельная старая тестовая заглушка HTTP потребовала исправления 0.1.7.
