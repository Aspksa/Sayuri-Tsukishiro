## FIX-002 — Кодировка Windows launcher
- Статус: `done` после успешного CI.
- Источник: реальный запуск пользователем версии 0.1.3.
- Причина: CMD/Windows PowerShell 5.1 некорректно интерпретировали UTF-8-файлы с кириллицей.
- Исправление: ASCII-only BAT + UTF-8 BOM PowerShell + отдельная Windows CI-проверка.
- Версии: проект `0.1.4`, dev-tools `0.1.3`.
- Приёмка: Windows PowerShell parser в GitHub Actions проходит; BAT не содержит байтов >127; повторный запуск на Windows не выдаёт ParserError.
